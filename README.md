# LUP-SAC

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

## Installation

Install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

## Usage

You can run the federated learning simulation using the main execution script `federated_main_sac.py`. Use the `--dataset` and `--attack` arguments to configure your experiment.

### Dynamic Attack Execution Behaviors
* **Run All Attacks (Default):** If no `--attack` argument is specified, the framework will automatically execute all 9 supported attacks sequentially.
* **Run Multiple Specific Attacks:** You can pass multiple attack names separated by spaces to run them sequentially in a single session.

### Execution Examples

**Run all attacks sequentially on MNIST (Default behavior):**
```bash
python federated_main_sac.py --dataset mnist
```

**Run multiple specific attacks sequentially on ToN-IoT:**
```bash
python federated_main_sac.py --dataset ton_iot --attack label_flip sign_flip byzMean
```

## Paper Replication Guide (DT-BFL)

This repository is pre-configured to replicate the exact results from the **DT-BFL** paper ([DT-BFL: Digital Twins for Blockchain-enabled Federated Learning in Internet of Things networks](../DT-BFL.pdf)). 

The default hyperparameter values in `options.py` are strictly matched to the paper's "Table 3" configuration:
- **Total Clients ($M$)**: `50`
- **Percentage of compromised devices ($F$)**: `50%` (25 Byzantines)
- **Learning Rate ($\eta$)**: `0.001`
- **Global Rounds ($R$)**: `100`
- **Non-IID Skew ($S$)**: `50%`
- **Local Epochs ($E$)**: `1`
- **Default Attacks**: Runs all 9 attacks consecutively.

### How to Run

To replicate the paper's experiments, you only need to specify the dataset (and adjust the local batch size to `128` specifically for MNIST as done in the paper):

**A. MNIST Dataset (Batch Size: 128)**
```bash
python federated_main_sac.py --dataset mnist --local_bs 128
```

**B. ToN-IoT Dataset (Batch Size: 256)**
```bash
python federated_main_sac.py --dataset ton_iot
```

**C. CIFAR-10 Dataset (Batch Size: 256)**
```bash
python federated_main_sac.py --dataset cifar
```
> **Note on CIFAR-10 Models**: By default, CIFAR-10 runs with the standard `CifarCNN` model. The paper also evaluated `DenseNet121` and `ResNet-9`. To use those, you will need to manually instantiate them in `federated_main_sac.py` instead of `CifarCNN`.

## Results Logging & Analytics

The framework comprehensively logs experimental states at the end of every epoch into tracking CSV files (e.g., `all_results_mnist_LUP_SAC_0.5.csv`). The captured telemetry includes:

### Model Performance Metrics
* `Epoch`: The current global communication round ($1$ to $100$).
* `Train_Loss` / `Test_Loss`: The objective function error mapped over training and testing sets.
* `Test_Accuracy` / `Precision` / `Recall` / `F1_Score`: Standard classification criteria evaluating global model convergence.

### Defense Verification Metrics
* `Byz_Bypass_Count`: The absolute number of malicious clients that successfully evaded detection and leaked into aggregation.
* `Byz_Bypass_Rate`: The proportion of the malicious cluster allowed to influence the update.
* `Benign_Selection_Rate`: The retention rate of honest clients, ensuring the defense doesn't starve the global model of data.
* `Num_Selected`: Total count of clients actively pulled into the aggregation step.

### Reinforcement Learning Diagnostics
* `Alpha`: The continuous trust weight assigned by the SAC actor network ($\alpha \in [0, 1]$).
* `Actor_Loss` / `Critic_Loss` / `Entropy_Coeff`: Core loss and optimization parameters of the SAC architecture.
* `Reward`: Total reward scalar fed back to the agent.
* `R_dir` / `R_mag` / `R_rep`: Component-specific breakdowns of the reward vector tracking historical direction (Cosine similarity), magnitude anomalies ($L_2$ norm tracking), and the historical consensus reputation anchor.
* `Aggregation_Time_s`: Wall-clock computational overhead generated by the filtering and aggregation sequence.

## Configuration Arguments

The framework is highly customizable. Below are the available command-line arguments you can pass via `options.py`:

### Byzantine Attack Parameters
* `--attack` (str): The Byzantine attack method(s) to simulate. Accepts a single attack, multiple space-separated choices, or defaults to all if omitted. Options include: `random`, `noise`, `label_flip`, `sign_flip`, `byzMean`, `min_max`, `min_sum`, `lie`, `mpfa`. (Default: `label_flip`)
* `--num_byzs` (int): Number of malicious Byzantine nodes. (Default: `25`)
* `--agg_rule` (str): The gradient aggregation rule fallback. (Default: `Mean`)

### Federated Learning Parameters
* `--epochs` (int): Total number of global communication rounds/epochs. (Default: `100`)
* `--num_users` (int): Total number of clients in the federated network. (Default: `50`)
* `--frac` (float): The fraction of clients selected per round. (Default: `1.0`)
* `--local_iter` (int): Number of local training iterations per client. (Default: `1`)
* `--local_bs` (int): Local batch size for client training. (Default: `256`)
* `--lr` (float): Local learning rate. (Default: `0.01`)
* `--momentum` (float): SGD momentum parameter. (Default: `0.9`)

### System & Data Parameters
* `--dataset` (str): Name of the dataset to use (`mnist` or `ton_iot`). (Default: `mnist`)
* `--num_classes` (int): Number of output classes for the dataset. (Default: `10`)
* `--iid` (int): Set to `1` for IID data distribution, or `0` for non-IID. (Default: `0`)
* `--skew` (float): Data skewness parameter for non-IID settings. (Default: `0.5`)
* `--optimizer` (str): Type of local optimizer to use. (Default: `sgd`)
* `--device` (str): Compute device. Set to `cuda:0` for GPU or `cpu`. (Default: `cpu`)

### Semantic Data Defense & Veto Parameters
* `--semantic` / `--no-semantic`: Enable or disable the Semantic Distribution Defense module via Gradient Inversion. (Default: `True`)
* `--semantic_veto_threshold` (float): The MMD penalty threshold that triggers a hard reward override (Semantic Veto). (Default: `-0.015`)
* `--semantic_penalty_value` (float): The hard negative reward applied when the semantic veto fires. (Default: `-1.0`)
* `--semantic_sample_ratio` (float): Fraction of clients analyzed via Gradient Inversion per round. (Default: `0.3`)
* `--semantic_decay` (float): Temporal decay factor for unsampled client semantic scores. (Default: `0.9`)
* `--gi_iterations` (int): Max gradient inversion optimization steps. Set to `-1` for auto-scaling. (Default: `-1`)
* `--gi_batch_size` (int): Dummy batch size used for gradient inversion. (Default: `8`)
